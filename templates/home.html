Project Overview

About the Project

This project analyzes land use and land cover changes in Mangaluru Taluk using multi-temporal Sentinel-2 satellite imagery and machine learning.

Classified maps from 2018, 2022 and 2025 are used to examine land use distribution and changes across the study period.

Analysis Workflow

  1. Satellite data collection and preprocessing
  2. Land use classification using Random Forest
  3. Year-wise classification comparison
  4. Land use transition and change analysis
  5. Statistical and spatial result visualization
